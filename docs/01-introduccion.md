# 01 - Introducción a TicketDesk

## ¿Qué es TicketDesk?

TicketDesk es una plataforma de gestión de incidencias orientada a entornos empresariales.

Su objetivo es permitir que los usuarios de una organización puedan comunicar problemas o realizar solicitudes y que estas sean gestionadas posteriormente por los equipos técnicos responsables.

Un ticket tendrá un ciclo de vida completo desde su creación hasta su resolución y cierre.

## Problema que pretende resolver

En una organización pueden producirse diariamente diferentes tipos de incidencias:

- Problemas de acceso.
- Errores en aplicaciones.
- Problemas de hardware.
- Problemas de red.
- Solicitudes de permisos.
- Solicitudes de software.
- Consultas técnicas.

Gestionar estas incidencias mediante correo electrónico o mensajes dificulta su seguimiento.

TicketDesk permitirá centralizar toda esta información.

## Objetivos funcionales

La aplicación permitirá progresivamente:

1. Gestionar usuarios.
2. Crear tickets.
3. Clasificar los tickets.
4. Establecer diferentes prioridades.
5. Asignar tickets a técnicos.
6. Modificar su estado.
7. Añadir comentarios.
8. Mantener un historial de cambios.
9. Controlar los tiempos de atención y resolución.
10. Gestionar SLA.
11. Generar estadísticas.
12. Controlar el acceso mediante roles.

## Objetivos técnicos

El proyecto también tiene como objetivo aplicar conocimientos de desarrollo backend profesional:

- Java.
- Spring Boot.
- API REST.
- Bases de datos relacionales.
- JPA e Hibernate.
- Validación.
- Gestión de excepciones.
- Seguridad.
- Testing.
- Documentación de APIs.
- Contenedores.
- Integración continua.
